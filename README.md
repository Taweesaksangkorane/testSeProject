## 3. Project Summary

The Research Administration Division at Mae Fah Luang University currently manages research grant proposal information using PDF documents and internal Google Sheets. Staff must manually transfer information, while researchers cannot independently check their proposal status.

The proposed web-based system aims to help researchers manage proposal information, generate PDF documents, and check proposal status. Authorized staff will be able to review proposal information and update proposal statuses.
