## Personal Research Grant Management System for Mae Fah Luang University

A web-based system designed to improve the management of personal research grant proposals at Mae Fah Luang University.

## 1. Project Overview

The Research Administration Division currently manages research grant proposal information using PDF documents and internal Google Sheets. This process requires staff to manually transfer information, while researchers cannot independently check the current status of their proposals.

The proposed system aims to simplify the proposal management process by providing a web application where researchers can enter and edit proposal information, generate PDF documents, and check proposal status. Staff can review proposal information and update its status through the system.

The project focuses on improving convenience, reducing repetitive manual work, and making proposal status information easier to access.
